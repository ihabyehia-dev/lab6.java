# Java Lab 6 - Recursion and Search

Recursion exercises in Java, using a class called `UML` and a small console demonstration.

## Exercises
- Greatest common divisor (GCD)
- Factorial and Fibonacci sequence
- Powers and sums of digits
- Recursive linear search and binary search
- Checking order and summing array values

## Run
Import `UML.java` and `Main.java` into the Eclipse package `ihablab3`, then run `Main.java`.

## Important
These are learning-stage implementations. Some methods (especially power, binary search and boundary cases) need corrections and additional tests; do not treat them as a finished algorithms library.
